\section{Observation, labels and strict first alarms}
Time zero denotes the disturbance. A 20-ms clock supplies the prefix $y_0,\ldots,y_w$ with $w\in\{10,15,20,25\}$. The response starts at sample $w+1$. The archived 1,200-row aggregate training grid ends 19 s after the disturbance. The newly simulated records end 20 s after it. On all 1,200 parameter vectors a common-integrator check found identical minima for the two horizons at all four cutoffs. The final sample was never the minimum in the original training grid. The first crossing of the unperturbed event truth below 0.995 pu defines risk, regardless of where its minimum lies. This includes events whose crossing occurs before any alarm could have 200 ms of lead. The risk definition is held fixed for amplitude prediction, warnings and transfer.

The quality scale is $a=\max(0.005,\sqrt{\mathrm{mean}[(y-\bar y_{\rm pre})^2]})$ in 50-Hz-equivalent units. For the same 50 pre-disturbance samples and current window, $Q=\max\{\mathrm{sd}_0(y_{\rm pre}),\sqrt{\mathrm{mean}[(\Delta^3y)^2]/20}\}/a$, where $\mathrm{sd}_0$ uses the population denominator. Bins are $Q\le0.0025$, $0.0025<Q\le0.016$, and $Q>0.016$. The endpoint predictor receives the last deviation and the shared bin-dependent threshold, the full-window predictor receives the entire visible window and that same binning rule. Separate models have separate numerical references and thresholds.

For each safe development variant, take the lowest score among windows that visited a bin. Pool these minima and select order statistic $\lfloor0.10n\rfloor+1$ as the bin reference. A bin with no visits falls back to all development safe minima. Subtract that bin reference from each score. On safe calibration variants, take the lowest adjusted score across the four windows and use the same order rule for a single global cutoff. At inference compare in binary double precision by strict inequality. Ties can reduce the empirical alarm fraction below the nominal target. Reported thresholds saved as text are never read back for decisions. Persistence uses the last observed frequency; quadratic features concatenate its deviation with the linear and quadratic coefficients on normalised time.

For each physical event and measurement variant define $a$ as the first triggering decision time, using infinity if none triggers. For a crossing time $b$, the hit is $\mathbf1[b<\infty,\ b-a\ge200~\mathrm{ms}]$; for a safe event the false alarm is $\mathbf1[a<\infty]$. Each physical event, including every variant, is the resampling unit. All comparisons use 2,000 paired draws. Results estimate uncertainty conditional on the fitted models, calibration sets and empirical perturbation distribution. No family-wise guarantee is attached to the exploratory strata.

\section{Source data and evidence boundaries}
The source grid contains 1,200 combinations. New aggregate parameters are sampled independently and uniformly over $H\in[2,6]$ s, $D\in[0.5,2]$, $R\in[0.04,0.06]$, $T_g\in[0.2,1]$ s and $d\in[0.02,0.08]$ pu. Integration uses fourth-order Runge--Kutta at 5 ms. Exact five-parameter keys were checked against previous training, development, calibration and confirmation archives. Histories include shared-model experiments that cannot supply an independent physical system. Development and calibration were reused across studies. Only the event seeds for the prospective comparison were fresh. The confirmation seeds for parameters, noise and resampling are 421117, 421118 and 421119.

\paragraph{Historical fixed-cutoff and warning experiments.}
On monotone clean trajectories the net window drop and its mean slope are functions of the endpoint. Segment slopes, segment fits, quadratic terms and variational-mode-decomposition energies were compared in the original fixed-cutoff study. On the 232 clean grid-test events with a post-cutoff nadir, the boosted endpoint tree had RMSE 35.4 mHz. Adding quadratic terms, segment differences, fitted segment slopes or mode energies gave 11.2, 11.7, 11.8 and 18.0 mHz, respectively. This single-event error comparison motivated matching the endpoints across events. Splitting events by the timing of their nadir was an evaluation stratification; it was unavailable to online predictors. The matched-pair comparison in the main paper uses archive member predictions and re-extracted true suffix minima. Two candidate members can share the same reference event; paired resampling respects that dependence. The full clean waveform and the endpoint plus all chord residuals are one-to-one equivalent. ECGR compresses the residual by fitting endpoint-constrained basis functions under a working covariance and shrinkage.

The original representation gate switched from ECGR to quadratic to endpoint as $Q$ increased. Its adverse 30-dB fixed-estimator tail and the failed false-alarm protection in the original rolling 10\% comparison remain part of the evidence.

The previous five-condition confirmation yielded 1,220/2,025 effective hits and 1,025/9,975 false alarms for the quality-stratified full window, versus 787 and 961 for quality-stratified persistence. The differences were $+21.38$ [16.57,25.92] and $+0.64$ [$-0.24$,1.53] pp. The full-window contrast with a trained endpoint tree was added after viewing that confirmation: $+29.23$ [26.49,32.15] pp in effective hits. The gate was $-6.57$ [$-9.31,-3.91$] pp below the stratified full window. An even earlier five-condition comparison of the gate with ordinary persistence yielded $+16.21$ [12.28,20.17] pp in hits and $-1.08$ [$-2.05,-0.09$] pp in false alarms. In that earlier batch, the post hoc unstratified full-window minus gate hit contrast was $+2.84$ [$-0.30$,5.87] pp. These batches have different denominators and experimental roles.

The previous matched-test-false-alarm comparison of gate versus ordinary persistence used test labels to interpolate a 10\% false-alarm point. At 200 ms it yielded $+21.41$ pp in the aggregate experiment and $-47.14$ pp on 118 completed high-load IEEE 39-bus trajectories. Transferred aggregate thresholds produced no alarms there. Ten failed runs remained of unknown risk. Those older network trajectories overlap previously examined designs. They are retrospective evidence with a different disturbance distribution from the new transfer tests.

\paragraph{Limits of the archived warning and interval evidence.}
The original rolling-versus-fixed comparison gained 98 timely detections among early crossings and lost 15 among later crossings. A separate fixed-cutoff one-sided bound passed 10 of 21 historical acceptance checks. Under 20-dB correlated noise, the envelope incorrectly declared 10 of 105 unsafe events safe. These outcomes address opportunity and conservative amplitude bounds, respectively; neither measures the new full-window versus endpoint contrast.

\section{Residual estimation and historical representation tests}
Write $r=Lf$ where row $i$ of $L\in\mathbb R^{(n-2)\times n}$ subtracts the endpoint chord from interior observation $i$. Let $B\in\mathbb R^{(n-2)\times2}$ contain the symmetric and antisymmetric columns defined in the main text. With $S=(I+T)/2$, $T_{ij}=0.65^{|i-j|}$ for the $n$ observation errors, factor $LSL^\top=CC^\top$ using a lower triangular Cholesky factor. The shared endpoint errors therefore enter the covariance of the residuals. Set $z=C^{-1}r$ and $Z=C^{-1}B$. With the two-coefficient least-squares fit $\tilde\beta$, define $s^2=\|z-Z\tilde\beta\|^2/(n-4)$. The estimate is
\[
 \hat\beta=\arg\min_{\beta\in\mathbb R^2}\left\{\|z-Z\beta\|^2+4(s^2/v)\beta_2^2\right\}.
\]
Here $v$ is the frozen training mean of squared unpenalised cubic coefficients with a $10^{-8}$ Hz$^2$ floor. The multiplier 4 was selected in historical validation. At 0.50 s, $n=26$, giving 24 residuals and 22 residual degrees of freedom. For shorter rolling windows the same basis and working covariance are resized on the normalised time grid. The scale $s^2$ can include omitted physical dynamics. The coefficients describe finite-window shape rather than uniquely identifying governor parameters.

For $Q\le0.0025$ the original gate uses the frozen ECGR tree; above that boundary through $0.016$ it uses the quadratic tree; above $0.016$ it uses the trained endpoint tree. The gate compares the selected score with its own global cutoff. The quality-stratified raw, quadratic, persistence and endpoint policies instead retain their scoring representation and centre the score within its current bin before testing a separately calibrated global cutoff.

\section{Numerical development and target sampling}
ANDES 2.0.0 uses its distributed dynamic workbooks. The Kundur model uses four GENROU machines with TGOV1 governors and EXDC2 exciters. The IEEE 39-bus case contains ten GENROU machines, TGOV1N governors and IEEEX1 exciters. Static MATPOWER bus cases by themselves do not supply these differential states. Built-in switching actions are disabled. Loads retain constant-power active and reactive components. For each event the initial demand scale is drawn uniformly from 0.975 to 1.025. At 1 s, a constant increment in active and reactive demand is applied. The active increment is the specified fraction of total scaled active demand. Its reactive increment preserves the ratio of the affected load(s). The Kundur patterns step either of the two loads. The 39-bus patterns step four loads at descending load ranks (1,4,7,10) or (2,5,8,11), distributing the increment by active demand. Each pattern is equally likely. Patterns were sampled for controlled numerical coverage, without an estimate of real-world prevalence.

The two cases use meters (1,6,10) and (1,20,39), respectively. Positive online inertia weights are the ANDES system-base machine start-up times. The predictor uses the measured bus channels, while the outcome uses the weighted mean of machine rotor speeds. True pre-event COI and meter deviations were checked against $10^{-4}$ pu. The 1,051-point recording spans 0--21 s absolute time, with 50 genuine pre-event samples. The prior solver value is selected at each nominal sampling time with a $10^{-9}$ s round-off tolerance; the last accepted state can be nearly 20 ms old. Sensor, detector and actuator latency are outside this design.

At the initial extreme injection, one of two cases on each network failed (0.18 on Kundur and 0.15 on IEEE 39). Both are logged. Smaller and moderate development injections were then run on both systems with 20-ms implicit trapezoid, 10-ms implicit trapezoid and 10-ms backward Euler. Across eight pairwise checks, all crossing labels agreed, crossing-time differences were zero, the largest change in COI nadir was $1.28\times10^{-5}$ pu and the largest prefix meter difference was $2.28\times10^{-4}$ pu. These checks cover a small number of trajectories. The 100-design unscored pilots included 18 incomplete Kundur and 23 incomplete IEEE 39 runs. Formal ranges were narrowed independently by site after these pilots; this conditions the scientific population and does not repair the failed pilot trajectories.

As an additional numerical diagnostic, we selected the first completed positive pilot design by index on each system. The IEEE 39 crossing moved by one 20-ms sample under the refined methods. The Kundur design crossed at 2.58 s with both 20-ms and 10-ms trapezoid but at 2.70 s with 10-ms backward Euler. This 120-ms change exceeded the 60-ms development tolerance. The nadir lay close to 0.995 pu. At 5-ms integration steps the two methods crossed at 2.58 and 2.62 s; at 2.5-ms steps they crossed at 2.56 and 2.60 s. Both retained the risk label, and all four alarm windows remained eligible in this event. These results document integration sensitivity near the level crossing. They cannot substitute for rerunning every formal design at the smaller step.

\section{Numerical recovery of the original series}
We applied the original 20-ms trapezoidal integration and two 5-ms integrations (trapezoidal and backward Euler) to every failed training, development, calibration and test design. All attempts are retained. A sampled COI crossing before termination establishes risk. Only an entire 20-s post-disturbance trajectory can establish safety. If a complete safe trace conflicts with a known crossing, the outcome remains unknown. We prioritised complete traces and used the fixed fine-trapezoid, backward-Euler and original-step order within completion class. All recovered operating points use the original trained rules and binary thresholds. Known labels on a partial trajectory do not supply a full training nadir. Recovered safe development and calibration cases document selection in the original fit and were excluded from retuning. For the original successful events we recomputed noisy observations, scores and each first alarm from saved traces. Two successful designs per network were reintegrated on the original solver grid. The stored COI and measured waveforms matched exactly on those four designs. For the original aggregate test we regenerated all 2,400 events from the parameter seed through dynamics, measurement noise, trained scores and first alarms.

\section{Sampling and evaluation on the new disturbance support}
In the new experiments the step in active and reactive demand was distributed in proportion to the selected loads. All synchronous inertia constants were multiplied by the cell factor before power flow and integration. The numerical development grid had three initial load levels, three inertia factors and four disturbance fractions per network. From those trajectories we selected a representative cell for safety and each of the three crossing strata, preferentially with complete simulations. Within each prospective split we drew a cell uniformly and independently jittered its baseline load and step fraction by up to two percent. Crossing labels never enter that draw. The development-only design calculation targeted roughly 60 B events, 60 C events and 80 safe designs using pilot frequencies, with a test budget clipped to 300--720 per network. It selected 320 for each. With 60 independent paired differences bounded by one in magnitude, a worst-case normal half-width is about 25 percentage points. Accordingly this design can leave moderate interactions and small cost differences unresolved. No significance-based stopping or sample increase was used.

\section{Replaying and rebuilding the independent network study}
Run the following commands in the r4 delivery directory in PowerShell. The analysis uses the project Python environment and the simulator uses the archived ANDES environment. Each mode writes a separate execution log in r4.
\begin{description}
\item[Replay.] \verb|.\run.ps1 -Mode Replay| checks the r3 delivery, pilot and test hashes. It reads the original test trajectories, recomputes window scores with the archived models and binary thresholds, and checks every valid score, first alarm and training-range flag. It also rebuilds Tables 7 and 8 from per-design records. Outputs include \texttt{replay-policy.npz}, the count audit, measurement-specific CSV and per-window comparisons. No solver or estimator fit runs in this mode.
\item[Reintegrate.] \verb|.\run.ps1 -Mode Reintegrate| recreates the 240 test designs from the archived seed and sampling frame, checks the physical parameters against the saved design list, integrates into a fresh \texttt{reintegrated} directory and rescores using the original fitted policies. Outputs include per-design solver logs, trajectories and a paired comparison with archived first alarms. This command keeps the original calibration.
\item[Regenerate.] \verb|.\run.ps1 -Mode Regenerate| starts an empty r4 \texttt{support-control} directory from verified simulator, analysis and protocol files. It runs the pilot, freezes the design frame, integrates training, development and calibration splits, fits both model families, estimates offsets and thresholds, writes a new test lock, then draws and integrates the test split. Evaluation and verification rebuild the split ledger, valid-window scores, first alarms, absolute and paired results, training ranges and missing-outcome bounds. Both integration modes require an unused output directory so cached successes cannot stand in for fresh runs.
\item[Build.] \verb|.\run.ps1 -Mode Build| repeats the archive audit, traces one existing aggregate RK4 design, checks the transfer clocks, generates both manuscripts and compiles and renders every page. The local reproduction guide lists source and result paths. Only Replay and Build were executed for this revision.
\end{description}
