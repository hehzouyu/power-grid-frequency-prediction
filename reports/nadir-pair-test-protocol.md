# 独立近端点配对预测试验 v1

协议在查看正式测试结果前冻结。正式试验沿用单级二状态聚合仿真，固定比较历史梯度提升树的四种输入。历史扫描 35 对是开发证据。正式检验的推断范围是下列预定参数族与匹配设计。

## 1. 数据隔离与候选生成

- 原网格训练、验证、历史测试角色沿用 `grid-index.csv`。四个模型、标准化器和超参数按原链路重建，树和标准化器只使用原训练组。历史验证集不用于新选型，原 232 条条件测试只用于基准回归核对。冻结完成才生成配对。
- 原训练网格的 R 取 0.04、0.05、0.06，正式测试留出低、高两个 R 带 [0.041, 0.044] 和 [0.056, 0.059]。每带独立生成 32 个参考场景，R 带内均匀抽样。另四个参考坐标在配置给定范围内独立均匀抽样。这里的留出是相对于原模型拟合网格与 35 对开发扫描。历史连续参数档案曾覆盖相关 R 区间，因此用固定的新种子生成新事件，并拒绝与历史网格、连续确认、区间试验、扩展匹配参考或候选完全重合的参数（五维最大绝对差 ≤ 1e-9）。
- 每个参考事件生成 H、D、Tg 三种候选，分别乘以 0.8、1.5、1.5。每次只改变指定物理参数和用于匹配的缺额 d，R 在配对内相同。64 个参考事件与 192 个候选尝试预先定额，按参考、因素分配 ID。临界目标差不参与匹配求根或替换候选。允许出现限幅场景及截止前、截止时、截止后全局最低点。
- 在 d ∈ [0.02, 0.08] p.u. 上用 fzero 求候选与参考的干净截止点频差为零。求根用完整历史仿真入口，外层验收为绝对端点差 ≤ 0.10 mHz。端点公差、缺额括区间、目标差阈值、抽样范围/种子均写入 JSON。几何匹配失败、未达目标差、输入特征失败分别记账，失败无补抽。

## 2. 固定输入与报告口径

- A 为参考，B 为候选，真值与预测差统一按 B−A 计算。扰动绝对时刻 1.00 s，截止绝对时刻 1.50 s。模型只用扰动后 0–0.50 s 的 26 点。标签为绝对时刻 1.52–20.00 s 采样频率的最小值。噪声对照共用干净标签、配对及分组。
- 输入分别是端点、端点加 0–0.10 s 首尾斜率、端点加归一时间上的二次拟合一次/二次项、端点加三段最小二乘拟合斜率。分段为 0–0.16、0.16–0.32、0.32–0.48 s。所有预测沿用原训练设置。冻结时保存原档案、代码、配置和模型校验值，Python 推理只接收键和特征。
- 干净输入为主。压力对照只用 30 dB 模拟独立高斯白噪声，10 个复本。每条轨迹的噪声标准差等于其干净窗频偏 RMS 乘以 10^(−30/20)。同一输入供四模型共享，同一参考曲线的噪声在它的候选之间共享，A 和 B 噪声独立。压力对照沿用干净端点确定的配对。
- 主幅值分析使用几何匹配成功、可推理且真实绝对目标差 ≥ 2.00 mHz 的配对。绝对差 ≤ 0.50 mHz 记为真实并列，相同阈值定义预测并列。0.50–2.00 mHz 的非并列小差以及真实并列都保留在方向评价。方向按三类判对，真实并列且预测并列计正确；非并列真值被预测成并列计错；真实并列被预测为任一方向计错。主分析子集方向正确率另列。每个白噪声复本是一次方向判断，真实并列同时报告物理对数和复本判断数。
- 主误差为绝对差值误差 abs(Δ预测−Δ真值)。MAE、RMSE、P95 仅使用主幅值集合。噪声时聚合所有等次数复本，P95 用线性插值。相对端点的差值误差变化采用候选模型误差减端点模型误差，负值有利。二次拟合和分段拟合另相对初始变化率计算同一对比，用于判断增益是否超出初始斜率。
- 差异的 95% 区间用预定 5,000 次百分位 bootstrap。对两个 R 带分别有放回抽取该带 32 个参考事件。每次纳入选中参考的全部候选和噪声复本，先平均同一配对的复本差，再汇总主集合中的配对差。无有效配对的参考仍在重采样框内，空分母的重采样记为无效。报告含有效主配对的簇数及有效重采样次数。区间用于描述逐模型比较。
- 匹配失败率 = 几何匹配失败数 / 全部候选尝试数。特征失败是匹配后的单独状态，进入失败账本，并从可推理分母中明确扣除。若 Python 推理出现非有限结果、行键缺失或模型完整性检查失败，则整个运行标记失败，不发布基于部分推理的成绩。每次运行独立命名，保留原日志；同协议技术复跑使用新目录。

## 3. 执行顺序与输出

在项目根目录运行。使用现有 MATLAB，不需要新增工具箱。Python 沿用既有 NumPy、pandas、SciPy、scikit-learn 1.9.0 与自带依赖 joblib。

```powershell
python repro/audit_nadir_pair_evidence.py
powershell -NoProfile -ExecutionPolicy Bypass -File repro/run_nadir_pair_test.ps1 -RunName anchor-check-my-run -AnchorOnly
powershell -NoProfile -ExecutionPolicy Bypass -File repro/run_nadir_pair_test.ps1 -RunName independent-v1
```

第二条只验算历史基准，第三条从重新冻结开始执行正式试验。脚本使用分阶段日志。MATLAB 若在 Codex 沙箱中因启动偏好目录写入失败，按本机许可在沙箱外执行同一命令。

## 6. 证据不足时的写法

- 二次、分段相对端点的区间跨零。保留等端点目标确实可以不同的物理证据，以及既有网格平均增益。将新增结论写为“冻结模型在独立近端点集合中的增益证据不足”，把两种结果分别报告。
- 相对端点有支持、相对初始变化率的区间跨零。可写“端点之外的早期动态信息有预测价值”。将“额外曲率或分段变化带来独立收益”改为“现有设计未分离出超出初始变化率的收益”。
- 干净条件有支持、30 dB 下证据不足或反向。将配对预测结论限定在干净量测。保留噪声后的误差、方向和并列结果，用于界定适用范围。
- 匹配失败多、主配对或有效参考簇少、只有少数因素贡献。报告失败分布与可评价范围，将新证据定为探索性或证据不足。按照锁定规则输出，同次运行不修改阈值或补抽事件。
