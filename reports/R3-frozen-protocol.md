# R3 未见工况验证协议

本协议在试算和读取 R3 结果前锁定。R2 产物保留。R3 采用 ANDES 的 IEEE 39 节点模型与相同的惯量中心频率越限判据，以三节点频率均值为输入。主要检验固定预测器在负荷外推时的表现，次要检验为未见扰动分布。R3 的二次拟合以聚合开发网格拟合，与 R2 使用目标系统校准场景折外拟合的版本存在差异。因此两轮数值不可用于归因分析或直接合并。

设计清单由 `repro/run_round3_scenarios.py` 的固定种子 39193019 生成。计划 144 个物理场景。64 个目标系统校准场景使用四个新负荷水平（0.956、0.982、1.018、1.044）与既有两类分布式负荷位置。主测试块 64 个场景全部位于校准负荷范围外（0.923、0.936、1.064、1.077），使用同两类位置。次测试块 16 个场景使用未见的母线组合及两个校准范围内的新负荷水平。每个负荷水平和位置组合固定抽取五个较低阶跃与三个较高阶跃。试算只读取校准组的四个预定场景。正式批次跑完整清单并记录全部收敛失败，不按观测结果追加样本。任一测试块缺一类时，相应指标记为不可估计。

持续性、二次拟合和非负跌幅残差共享输入、决策时刻、噪声和分级阈值规则。前两者为主对照，残差为次要对照。二次拟合与残差均在旧聚合开发网格上拟合，R3 校准场景仅用于阈值。每个物理事件评估干净、40 dB 白噪声、20 dB 白噪声和相关噪声，等权混合。30 dB 边界及扰动时噪声突变为压力条件，不进入校准或主混合。噪声实现使用预先固定的种子 39193020，与 R2 的种子范围不重合。

10% 为主目标虚警率，5% 和 20% 用于敏感性分析。逐块报告实际虚警、及时命中、条件提前量与物理分母。区间按物理事件聚类重采样，各噪声版本随事件一同抽取，推断限于给定压力设计。不对封存集重新选阈值。三档曲线只展示各预设阈值的工作点，实际虚警不一致时不视为相同。校准内每级至少有一个未越限场景版本方可选择该级经验阈值；校准分母和样本稀疏性一并报告。

次测试块同时使用范围内新负荷水平与新位置组合，因此它评估联合迁移，不能单独归因于位置变化。低负荷与高负荷外推的结果可由事件表按负荷水平追溯。区间只反映给定负荷水平集合中的事件差异。
